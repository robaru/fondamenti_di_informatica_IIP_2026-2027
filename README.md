# Fondamenti di Informatica (IIP) — A.A. 2026/2027

Materiale delle lezioni del corso di Fondamenti di Informatica, con esempi ed esercizi in linguaggio C.

## Struttura del repository

- `AAAA-MM-GG/` — codice delle lezioni dell'anno in corso, una cartella per lezione (es. `2026-10-05/`).
- `to_be_revised/` — materiale dell'anno precedente, che verrà aggiornato durante il corso.

## Risorse online

- [cs50.dev](https://cs50.dev) — ambiente di sviluppo online (VS Code nel browser) per scrivere, compilare ed eseguire codice C senza installare nulla. Richiede un account [GitHub](https://github.com).
- [cs50.ai](https://cs50.ai) — assistente AI (CS50 Duck) per l'apprendimento e il debug del codice.
- K. N. King, *C Programming: A Modern Approach*, 2ª ed., W. W. Norton, 2008 — libro di testo di riferimento.
- [Wikibooks — C Programming](https://en.wikibooks.org/wiki/C_programming) — manuale online gratuito sul linguaggio C.
